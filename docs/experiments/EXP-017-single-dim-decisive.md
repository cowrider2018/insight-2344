# EXP-017 決斷夜單一籌碼子面覆蓋

- 日期／狀態：2026-07-11 ｜ **REJECT**
- 假設：EXP-016 三面多數決在衝突日整體是反指標，改分別測 chips/branch/holders 單一子面，是否有某一面單獨在衝突日優於 SOX（可局部覆蓋）
- 資料：同 EXP-016（決斷夜子集 n=140，as-of `<D`）
- 方法：逐面（非多數決）與 sign(SOX) 比對，衝突日分別計算跟SOX／跟該面命中率＋覆蓋後全日命中率

## 數字

- 決斷夜基準 70.71%（n=140）
- chips 衝突 n=67：跟SOX 62.69% vs 跟chips 37.31%（p=0.050）→ 覆蓋後 58.57%（Δ−12.1pp）
- branch 衝突 n=74：跟SOX 62.16% vs 跟branch 37.84%（p=0.047）→ 覆蓋後 57.86%（Δ−12.9pp）
- holders 衝突 n=66：跟SOX 65.15% vs 跟holders 34.85%（p=0.019）→ 覆蓋後 56.43%（Δ−14.3pp）

## 判定與理由

REJECT。三面單獨測試呈現一致形態：與 SOX 衝突時，SOX 側命中率雖較決斷夜基準略降（62–65% vs 70.71%，衝突日本身較難），但仍穩定 >50%；籌碼面剛好是其鏡像互補（因 sign 二元、conflict 定義即相反號，非中性日下兩者命中率互補=100%），故籌碼側必然 <50%。三面獨立驗證排除了 EXP-016 是多數決手法特有瑕疵的可能，確認「決斷夜衝突日跟籌碼」機制性不成立——SOX 隔夜驅動在決斷夜對 2344 是主導因子，籌碼面在此子集無獨立方向資訊可覆蓋。
