# EXP-016 決斷夜籌碼共識覆蓋

- 日期／狀態：2026-07-11 ｜ **REJECT**
- 假設：決斷夜（\|SOX\|≥1%，現行純跟隔夜規則基準 70.71%）中，籌碼三面（chips/branch/holders）方向共識與 SOX 衝突時，改跟籌碼共識可提升決斷夜全日命中率
- 資料：`daily_decision` 決斷夜子集（2025-07-01起，n=140）；chips/branch/holders 皆 as-of `<D`（沿用 `backtest.extract_features` assert）
- 方法：三面簡單多數決 vs sign(SOX)；分衝突/同向日；模擬「衝突日改跟籌碼」覆蓋規則後的決斷夜全日命中率

## 數字

- 決斷夜基準（純跟SOX）70.71%（n=140）
- 衝突日（籌碼≠SOX）跟SOX命中率 64.18%（n=67, p=0.027）；同向日（籌碼=SOX）76.71%（n=73, p<0.001）
- 衝突日若改跟籌碼共識：命中率僅 **35.82%**（n=67, p=0.027）——籌碼在此子集是**反指標**，非有效覆蓋源
- 覆蓋規則後決斷夜全日命中率 57.14%（Δ**−13.6pp**，大幅劣化）

## 判定與理由

REJECT，敗在關卡⑤等效測試（覆蓋規則整合後不升反降）。籌碼三面共識在與 SOX 衝突時方向命中率僅 35.82%，明顯劣於擲幣，覆蓋只會拖累決斷夜命中率。附帶發現：**同向日**（籌碼確認SOX）命中率 76.71%，較基準 +6pp，顯示籌碼一致性可作「conviction 加強」的質性訊號（不變更方向判斷），但不足以支撐本輪「覆蓋方向以推升勝率」之假設，故整體 REJECT。此發現留給下一輪：改用單一籌碼面（而非三面多數決）或改當信心層而非方向覆蓋。
