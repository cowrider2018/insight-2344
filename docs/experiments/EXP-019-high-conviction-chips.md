# EXP-019 決斷夜高強度籌碼分歧覆蓋

- 日期／狀態：2026-07-11 ｜ **REJECT**
- 假設：EXP-016/017/018 的「衝突」只看正負號、混入近零雜訊；改只在籌碼三面平均訊號強度 \|avg\|≥門檻 時視為高強度分歧才覆蓋，過濾雜訊後應更可靠
- 資料：同 EXP-016/017/018（決斷夜子集 n=140）
- 方法：預先掃三個強度門檻 0.2／0.35／0.5，各自計算高強度分歧日的跟SOX vs 跟籌碼命中率與覆蓋後全日命中率

## 數字

- 決斷夜基準 70.71%（n=140）
- 門檻0.2：n=51　跟SOX 58.82%　跟籌碼 41.18%（p=0.262）→ 覆蓋後 64.29%（Δ−6.4pp）
- 門檻0.35：n=31　跟SOX 48.39%　跟籌碼 51.61%（p=1.000）→ 覆蓋後 71.43%（Δ**+0.7pp**，但 p=1.000 無顯著性）
- 門檻0.5：n=21　跟SOX 57.14%　跟籌碼 42.86%（p=0.664）→ 覆蓋後 68.57%（Δ−2.1pp）

## 判定與理由

REJECT，敗在關卡②顯著性。三個門檻結果非單調（+0.7pp / −6.4pp / −2.1pp 交錯），0.35 門檻唯一轉正的樣本 p=1.000（等同擲幣），屬多重檢定下的雜訊巧合，非穩健訊號——若照此挑選門檻直接違反 reject-by-default 精神（同 EXP-005「極端箱 p≥0.36」前例，數字看似轉正但無法通過顯著性）。至此四輪一致確認：無論用多數決、單面、弱磁點分層、或強度門檻切分，決斷夜衝突日籌碼面皆無法穩健覆蓋 SOX。
