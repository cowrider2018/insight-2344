# EXP-009 MU 財報行事曆

- 日期／狀態：2026-07-11 ｜ **BLOCKED-DATA**
- 假設：於每日報告質性標註「美光財報將至/剛過」（報告改善路徑，不入加權、不做統計主張）。
- 資料：Yahoo quoteSummary calendarEvents（探針 **HTTP 401**，2023 起需 cookie+crumb，免金鑰自動取得不成立）；歷史財報日以 Micron IR 新聞稿寫死 8 筆供脈絡分析
- 方法：探針可得性＋歷史脈絡（8 次財報反應日的 2344 |漲跌| vs 全樣本）

## 數字

- 探針：HTTP 401（免金鑰不可得；替代源 NASDAQ API 需特殊 headers 亦不穩定）
- 歷史脈絡（n=8，純描述）：反應日平均 |漲跌| **3.21%** vs 全樣本 **3.13%** → 無波動放大
  - 分布極端雙峰：2024-09~2025-12 六次僅 0.24~3.43%，2026-03/06 兩次 9.84%/7.07%（記憶體週期高點才有戲）

## 判定與理由

BLOCKED-DATA（Stage 2 資料關卡不過）。且即使資料可得，「財報日波動放大」的質性前提在 8 事件歷史中不成立（平均無異於基準）——標註反而可能誤導讀者高估事件風險。報告改善型 ACCEPT 需「資料可得＋主張誠實」，兩者皆缺。
