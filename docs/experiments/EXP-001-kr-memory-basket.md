# EXP-001 韓國記憶體同業籃

- 日期／狀態：2026-07-10 ｜ **REJECT**
- 假設：海力士(000660.KS)＋三星(005930.KS) 等權報酬相對 KOSPI(^KS11) 的 D-1 強弱＝記憶體族群專屬資金流，對 2344 次日方向有「獨立於 SOX」的預測力（維度或 risk_off 型 veto，預期平淡夜 >53% 或輪動期 veto +5pp）。
- 資料：Yahoo chart API（免費免金鑰）｜三檔各 483 交易日（2024-07-11~2026-07-09）｜韓股 14:30 TST 收盤 → 06:00 已知，as-of `kr_date < D`（以交易所時區標日期，避免美東時區錯標）
- 方法：`rel_1d`＝雙雄等權−KOSPI（D-1）、`rel_3d`＝近 3 韓股日累積、`abs_1d`＝雙雄等權；sign → 次日方向；中性帶 ±1%、無擬合參數（無需 walk-forward）；視窗 2025-07-01~2026-07-10（n=250，KR 覆蓋 247/250）

## 判定與理由

REJECT。三個訊號各敗一關：
- `rel_1d` 敗關卡④（SOX 影子）：edge 集中決斷夜 61.3%（且遠低於既有「跟 SOX」~71%，無增量），平淡夜 52.1% ≤53%＝擲幣；corr(rel_1d, SOX)=+0.214 佐證同源。
- `rel_3d` 敗關卡③（OOS 55.4% < in-sample 59.0% − 2pp）；平淡夜 56.3% 是唯一亮點但樣本外衰減，依 reject-by-default 不採。
- `abs_1d` 敗關卡②（in-sample p=0.156）＋④（平淡夜 50.7%）。
- Overlay 路徑直接反向：KR 記憶體相對弱＋SOX 漲時 2344 反而更常漲（72%），與「輪動領先」假設相反 → 2026-06 的海力士輪動教訓不經由 D-1 韓股相對強弱傳導（risk_off 用的外資流仍是較好代理）。
