# EXP-018 決斷夜弱磁點分層籌碼覆蓋

- 日期／狀態：2026-07-11 ｜ **REJECT**
- 假設：\|SOX\|處於 1–2%（弱磁點）決斷夜跟SOX命中率較低，此窄帶內籌碼三面共識具局部覆蓋優勢（強磁點 \|SOX\|≥2% 不動）
- 資料：同 EXP-016/017（決斷夜子集 n=140）
- 方法：按 \|SOX\| 分弱[1,2)/強[2,+) 兩帶，弱帶內衝突日模擬覆蓋規則

## 數字

- 弱磁點跟SOX命中率 68.97%（n=58）／強磁點 71.95%（n=82）——差距僅 3pp，遠不如 EXP-010 \|SOX\|≥3% 極端帶的效果顯著
- 弱磁點內衝突日 n=30：跟SOX 66.67% vs 跟籌碼 33.33%（p=0.099）——同 EXP-017 鏡像互補形態
- 僅弱磁點衝突日覆蓋後決斷夜全日命中率 63.57%（Δ**−7.1pp**）

## 判定與理由

REJECT。弱磁點帶本身跟SOX命中率並未顯著低於強磁點（68.97% vs 71.95%，非 EXP-010 那種可解釋的單調斷層），窄帶條件化未能製造出「SOX較弱、籌碼可補位」的情境；衝突日籌碼側依然是鏡像反指標，覆蓋後全日命中率再度下降。至此三輪（EXP-016/017/018）從三種角度（多數決／單面／弱磁點分層）一致證實：**決斷夜衝突日跟籌碼無正向資訊**，非單一手法瑕疵。
